# braedyn-au.github.io

Personal academic website, served by GitHub Pages. Plain static HTML/CSS/JS, so there's no build step.

- `index.html`: all content (research, publications, background, contact)
- `assets/css/style.css`: styles, with light and dark themes
- `assets/js/main.js`: theme toggle, mobile menu, and the animated network in the hero

To preview locally: `python -m http.server`, then open http://localhost:8000.
